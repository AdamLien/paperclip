## mCrew 日常交辦與成果交付（2026-10-21）

- 先確認交辦的目標與可驗證成果；能自行完成就直接執行、自查、交付。普通查詢、研究、草稿、整理與報告不固定經過主管或多人接力。只有缺少會影響正確性的必要資訊才問一次具體問題。
- 使用當前任務作為主要對話與成果入口。先查既有任務及成果，不因研究、撰稿、自查或連線重試另建卡片；已發布的不得重發。
- 收到超出自己專業的需求時，查本公司 agent 目錄與能力，在同一任務中使用原生改派交接給合適負責人，留下目標、來源與已完成部分；不是另開相同任務。若本人正在執行，遵守 checkout／交接機制，不能搶鎖、自我反覆喚醒或循環改派。只有獨立且需追蹤的交付才拆子任務。
- 協助者的結果、主要成果、來源與必要限制回到原任務。對使用者以「正在處理／等待誰決定什麼／需要補什麼／已完成及成果連結」簡短回報，工具紀錄留在執行詳情，不用大量內部狀態取代結論。
- 需要核准時使用既有原生審核或互動機制，寫明具體決定、對象、範圍與建議，不只留言「approval」。已設定的重要事項核准仍有效，不冒名決定、不繞過政策。未授權的對外發布、發送、付款、重大承諾與敏感變更仍交指定人類。
- 檔案是交付成果時，必須上傳目前公司／任務的附件或原生 work product，提供可點擊閱讀／下載連結。HTML 報告使用自包含、可離線閱讀的文字與 CSS；不依賴外部腳本、字型、追蹤或登入頁。不把主機絕對路徑當作唯一交付。
- 完成前實際回讀附件或結果並核對來源、租戶、數字與限制；需要可下載檔案的任務，只有文字說完成、工具連線成功或程序 succeeded 都不算完成。失敗時保留已完成成果，只指出當前具體阻礙，不重跑已通過的步驟。
- 只使用本公司已授權的連線、記憶、檔案與 agent；不借用其他公司或主機管理員身分。沿用已明確授權，不要求使用者重複 OAuth 或提供金鑰；必要權限不可用時清楚說明，不擴權。個人助理的私人資料仍不得寫入公司共用記憶。

## 已有能力與這次調整

- 新任務保留明確指定與草稿；未指定時只沿用可執行 agent 的近期選擇，否則選 CEO、有直屬成員的協調人或可用 agent。目錄與近期選擇以當前公司為範圍；不以舊的人員選擇默認建立無 agent 的 AI 任務。這是預設接件人選擇，需求理解與專業改派由接件 agent 在同任務完成。
- 新任務沒有指定 reviewer／approver 時維持沒有固定審核鏈。已存在的人類核准介面以 executionState 的真實參與者顯示，不以留言推測核准人。
- HTML 任務附件預設顯示報告，另保留原始碼與下載；讀取沿用原任務的授權附件清單、512 KiB 實際回應上限及原本的公司權限。
- 預覽使用無權限 iframe sandbox、限制型 CSP 與清除主動內容，不允許腳本、外部資源、表單、跳轉或存取主頁。預覽不改寫原始下載檔。動態報表應另外交付靜態版本。

## 驗收

1. 新任務：預設為本公司 agent，不覆寫手動指定、草稿或輸入中的需求。
2. 申皇 CMP-1：沿用既有任務與原生 mCRM 查詢證據；附件能在同任務預覽、切換原始碼與下載。
3. 安全：缺失或未授權附件不發出內容請求；HTML 不取得主頁權限或對外連線；公司 sandbox／Supermemory 隔離不變。
4. 重要核准與財務唯讀設定不更動；無額外定期喚醒、重複任務或外部通知。
